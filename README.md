# Budget Manager

Single-page personal budget manager in HTML, CSS and JavaScript.

## Features

- Income and expense tracking
- Runs directly in the browser, no install

## Tech Stack

- HTML/CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/budget-manager.git
cd budget-manager
# open index.html in your browser, or serve the folder:
npx serve .
```
